# 📘 Maths Simplified
A simple and interactive web app to understand core math concepts like **Set Theory** and **Arithmetic Progression**.

---

## 🚀 Features
* 🧩 Set Operations (Union, Intersection, Complements)
* 📈 AP Calculator (nth term & sum)
* 🎨 Clean UI with animations
* 📱 Responsive design

---

## 🛠️ Tech Stack
* HTML
* CSS
* JavaScript

---

## 📂 Structure
index.html

style.css

script.js

---

## ▶️ Run
Just open `index.html` in your browser.
